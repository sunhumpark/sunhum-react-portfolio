# Sunhum Park React Portfolio — COMP229 Assignment 1

## Run locally
1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Before submitting
- Replace `public/Sunhum-Park-Resume.pdf` with your real resume using the same filename.
- Replace the About-page photo placeholder with your own professional headshot.
- Replace `your.email@example.com` in `src/pages/Contact.jsx`.
- Update education dates/details if needed.
- Replace project placeholders/images with screenshots of your actual projects if your instructor expects images.
- Test all six pages and the Contact form.
- Commit major stages to GitHub, then deploy to Vercel/Netlify/Render or another cloud host.
